Data collected

  • OAuth Twitch token — used to interact with the Twitch API (stream category, events)
  • Steam ID — used to read your game library via the Steam API

Data Transfers

Your data is sent only to the Twitch and Steam APIs for the application to function. No third-party sharing.

Retention Period

Your data is kept for the lifetime of your account and deleted when you delete it.

Your Rights

You can delete your account from the Settings page. For any request, contact the administrator by email.
