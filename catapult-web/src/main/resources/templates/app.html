Résoudre le profil privé Steam

Game detection requires access to your Steam game list. Choose one of the options below:

Option 1 — Rendre le profil public

Set your Steam profile and game details to public in your privacy settings.

Ouvrir les paramètres Steam →

Option 2 — Token personnel Steam

Créez une clé API personnelle sur steamcommunity.com/dev/apikey en utilisant le domaine 0.0.0.0, puis collez-la ci-dessous.

  1. Allez sur steamcommunity.com/dev/apikey
  2. Dans le champ "Nom de domaine", saisissez 0.0.0.0
  3. Acceptez les conditions et cliquez sur "Enregistrer"
  4. Copiez la clé générée et collez-la ci-dessous

Steam nous bloque temporairement

Vous pouvez contourner cette limitation en fournissant votre propre clé API Steam. Elle sera utilisée uniquement pour votre compte.
